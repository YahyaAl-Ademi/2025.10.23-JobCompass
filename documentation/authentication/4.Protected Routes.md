        Server->>Server: Verify JWT signature and expiration
        Server->>Server: Check token against blacklist

            Server->>API: Return 401 error<br/>"No token provided" or "Invalid token"
            deactivate Server

            deactivate Server

            ProtectedRoute->>User: Display updated content
            deactivate ProtectedRoute
        end
    end

## Key Components & Files

### Client Side

- **ProtectedRoute.jsx** (`client/src/components/ProtectedRoute.jsx`)
  - Route protection wrapper component
  - Authentication state checking
  - Redirect logic for unauthenticated users

- **UserContext.jsx** (`client/src/context/UserContext.jsx`)
  - Provides authentication state
  - Handles logout on authentication errors
  - Global user session management

### Server Side

- **verifyToken** (`server/src/middleware/authVerify.js`)
  - Middleware for protecting API routes
  - Token verification and blacklist checking
  - User data attachment to requests

- **Protected Routes** (`server/src/routes/user.js`)
  - Routes requiring authentication
  - Various user operations (profile, favorites, etc.)

## Protected API Endpoints

### User Profile Management

- `PUT /users/profile` - Update user profile
- `POST /users/update-avatar` - Update user avatar
- `POST /users/change-password` - Change user password
- `POST /users/change-skills` - Update user skills

### Favorites Management

- `POST /users/favorites/toggle` - Add/remove job from favorites

### Account Management

- `DELETE /users/delete/:user_id` - Delete user account
- `GET /users/me` - Get current user profile

## Route Protection Logic

### Client-Side Protection

```javascript
// ProtectedRoute component logic
if (!user.user_id) {
  return <Navigate to="/login" replace />;
}
return <Component {...props} />;
```

### Server-Side Protection

```javascript
// Middleware application
userRouter.get("/me", verifyToken, getMe);
userRouter.put("/profile", verifyToken, updateProfile);
userRouter.post("/favorites/toggle", verifyToken, toggleFavoriteJob);
```

## Security Features

- **Dual Protection**: Both client and server-side validation
- **Automatic Logout**: Sessions terminated on token issues
- **Middleware Chain**: Consistent authentication across all protected routes
- **Token Validation**: Every protected request validates the token
- **User Context**: Secure user data attachment to requests

## Error Handling

- **401 Unauthorized**: Invalid, expired, or missing tokens
- **Redirect Flow**: Automatic redirect to login for unauthenticated access
- **Session Cleanup**: Automatic logout on authentication failures
- **Graceful Degradation**: Proper error states and user feedback

## Access Control Flow

### 1. Route Access Attempt

- User navigates to protected route
- ProtectedRoute component checks authentication state

### 2. Authentication Check

- If unauthenticated: redirect to login
- If authenticated: render protected component

### 3. API Request Protection

- Each API request passes through verifyToken middleware
- Token validated against blacklist and expiration

### 4. Error Recovery

- Authentication failures trigger automatic logout
- User redirected to login with appropriate messaging

## User Experience

- **Seamless Navigation**: Authenticated users access protected content directly
- **Clear Redirects**: Unauthenticated users guided to login
- **Session Persistence**: Users remain logged in across browser sessions
- **Security Transparency**: Authentication handled automatically in background

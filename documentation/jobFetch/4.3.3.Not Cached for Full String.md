    participant FrontendNetwork as HTTP Network Layer
    participant ExpressApp as Express Server<br/>app.js
    participant JobController as Job Search Controller<br/>jobData.js<br/>`searchJobs()`
    participant CachedJobsService as Cached Jobs Service<br/>getCachedJobsBySearchString.js
    participant NeonDB as Neon Database<br/>search_strings / jobs / search_strings_jobs
    participant RealJobSearch as Real Job Search Service<br/>rapidAPIfetch.js

    Note over JobsContext,PersistJobSearch: Phase 4.3.3: Not Cached for Full String
    activate JobController

    Note over JobController: Full search_string was NOT found in cache (from Phase 4.3.1)
    JobController->>JobController: Split search terms into words:<br/>`searchWords = search_string.split(/[\\s\\-.'/]+/)`

    Note over JobController: Create concurrent fetch promises<br/>for all search words
    loop For each search word (index i)
        JobController->>CachedJobsService: call `getCachedJobsBySearchString()`<br/>Check if word is cached
        activate CachedJobsService
        CachedJobsService->>NeonDB: Query `search_strings` table
        activate NeonDB
        alt Word cached in DB
            NeonDB-->>CachedJobsService: Word found
            CachedJobsService->>NeonDB: Query `jobs` table via `search_strings_jobs`
            NeonDB-->>CachedJobsService: Return cached jobs
            deactivate NeonDB
            CachedJobsService-->>JobController: Return cached jobs array
            deactivate CachedJobsService
        else Word NOT cached
            CachedJobsService-->>JobController: No cached jobs
            JobController->>JobController: Fallback to real search
            alt i >= 2 AND searchWords.length > 2
                Note over JobController: Apply throttling:<br/>setTimeout (i-1) * 700ms
                JobController->>RealJobSearch: call `rapidAPIfetch(searchWord)`
            else
                JobController->>RealJobSearch: call `rapidAPIfetch(searchWord)` (immediate)
            end
            activate RealJobSearch
            RealJobSearch->>RapidAPI: GET LinkedIn Job Search API
            RapidAPI-->>RealJobSearch: Return raw job data

            loop For each job in results
                RealJobSearch->>ProcessRapidAPIjob: call `processRapidAPIjob(job)`
                activate ProcessRapidAPIjob
                Note over ProcessRapidAPIjob: Normalize job fields
                ProcessRapidAPIjob-->>RealJobSearch: Return normalized job
                deactivate ProcessRapidAPIjob
            end
            RealJobSearch-->>JobController: Return normalized jobs array
            deactivate RealJobSearch

            JobController->>JobController: Store results in `inProgressSearches[searchWord]`
            JobController->>FetchPersister: call `fetchPersister(searchWord, ...)`<br/>(non-blocking)
            activate FetchPersister
            FetchPersister->>PersistJobSearch: call `persistJobSearch()`
            activate PersistJobSearch
            PersistJobSearch->>NeonDB: Upsert search_strings / jobs / search_strings_jobs
            deactivate PersistJobSearch
            deactivate FetchPersister
        end
    end

    JobController->>JobController: `await Promise.all(fetchPromises)` to aggregate results

    JobController->>JobController: Aggregate results from all words<br/>Remove duplicates using Set of job IDs<br/>Maintain insertion order

    JobController->>ExpressApp: Return response with<br/>aggregated, normalized jobs
    ExpressApp->>FrontendNetwork: HTTP 200<br/>{ success: true,<br/>  result: [job1, job2, ...] }
    FrontendNetwork->>useFetch_1: Response received
    useFetch_1->>useFetch_1: Parse JSON response
    useFetch_1->>useFetch_1: Set `isLoading = false`
    useFetch_1->>JobsContext: Call `handleJobFetchResults(data)`<br/>(callback function)
    deactivate JobController
